# Awesome DESIGN.md Skill

This skill provides on-demand access to analysed `DESIGN.md` files from 70+ premier websites and platforms. Use this skill whenever you need to build or style interfaces that match the design language of a specific brand.

## How to Use

1. **Locate the Brand**: Browse the directories under `design-md/` to find the target brand (e.g., `design-md/linear.app/`, `design-md/stripe/`, `design-md/vercel/`, `design-md/apple/`).
2. **Read the Design Guide**: Read the `DESIGN.md` file inside that brand's directory.
3. **Apply the Tokens & Guidelines**: Implement the colors, typography, border radii, card layout styles, gradients, and micro-animations defined in the document to wow the user.
